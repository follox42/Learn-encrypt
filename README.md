# Learn-encrypt

> **Warning**: This is a learning project. Do not use these implementations in production. Real cryptography requires battle-tested libraries.

## Purpose

Personal journey to understand encryption by implementing algorithms from scratch in C.

## Structure

```
docs/           # Theory documentation (English, no code)
src/            # C implementations
```

## Learning Path

1. **Fundamentals** - Binary, bits, XOR, ASCII, hexadecimal
2. **Classical Ciphers** - Caesar, Vigenère, substitution
3. **Symmetric Encryption** - XOR cipher, DES, AES
4. **Asymmetric Encryption** - RSA
5. **Hash Functions** - MD5, SHA-256
